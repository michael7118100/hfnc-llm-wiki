# 🫁 高流量氧氣鼻導管（HFNC）臨床知識庫（LLM Wiki）

## 📚 知識庫目錄（Knowledge Index）

1. **[01_基礎原理與生理機制](./01_基礎原理與生理機制.md)**
   - 核心摘要：四大生理效應（沖洗死腔、低度 PEEP、精準 FiO2、37°C 加溫加濕）。
2. **[02_臨床適應症與禁忌症](./02_臨床適應症與禁忌症.md)**
   - 核心摘要：第一型急性低血氧呼吸衰竭與拔管後支持；排除 GCS ≤ 8、未引流氣胸與嚴重酸中毒。
3. **[03_初始參數設定指南](./03_初始參數設定指南.md)**
   - 核心摘要：鼻塞 < 50% 鼻孔規範，先設流速（Flow）、再調氧濃（FiO2）、微調溫度（Temp）。
4. **[04_療效評估與失敗預警（ROX Index）](./04_療效評估與失敗預警（ROX%20Index）.md)**
   - 核心摘要：2hr / 6hr / 12hr 動態監測閾值，防止延誤插管風險。
5. **[05_脫離（Weaning）流程與照護要點](./05_脫離（Weaning）流程與照護要點.md)**
   - 核心摘要：兩階段退場原則（先降 FiO2 至 ≤ 0.40，再降 Flow 至 ≤ 15–20 L/min）。
